# Contributing

Maintainer: Boshen Chen (@ObeliskGate)

Keep changes scoped to source, tests, documentation, or reproducible build
configuration. Do not commit models, datasets, bags, traces, profiles, logs,
SIF images, credentials, or generated benchmark results. Run the applicable
source/unit tests and XML/docs checks before submitting a change. Preserve
upstream copyright and license notices when modifying derived files, and add
a short modification notice when the change is substantial.
