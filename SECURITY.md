# Security

Please report suspected security issues privately to
`unnamets@gmail.com` with a concise description, affected revision, and
reproduction details. Do not include credentials, private model/data assets,
or site-specific logs in an issue or patch. This repository does not ship
runtime images or credentials; reports involving external ROS, CUDA, ROCm,
ONNX Runtime, model, or dataset providers may need to be sent to those
providers as well.
